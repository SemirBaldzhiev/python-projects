Project Repository

A collection of Python tasks and console applications.

  • 01. Hangman Game A hangman game in the console. You have to guess the chosen word from the computer. Yo have only 6 lives so you have to pick your letters very careful.
  • 02. Caesar Cipher Encode or decode a text which you type in the console.
  • 03. Simple Calculator Simple calculator with console interface which provides a 4 simple operations.
  • 04. Blackjack / 21 Simple console blackjack simulator.
  • 05. Number Guessing Game in which you have to guess a number which is randomly generated and based on the difficulty you chose you have a less or more attemts.
  • 06. Snake Game Traditional snake game written using turtle module and it is only available for desktop.
